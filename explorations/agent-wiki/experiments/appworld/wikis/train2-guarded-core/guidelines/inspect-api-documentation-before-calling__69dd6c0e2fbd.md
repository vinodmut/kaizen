# Inspect API documentation before calling

Before invoking any API, especially for unfamiliar endpoints, call the API documentation endpoint (e.g., show_api_doc or show_api_descriptions) to review required parameters, response schemas, and usage details.

## Rationale

Consulting live API documentation prevents errors from incorrect parameters or misunderstanding API behavior, leading to more reliable and maintainable code.
